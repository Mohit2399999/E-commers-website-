# ⚡ NEXUS TECH — Full-Stack E-Commerce Platform

A production-ready full-stack E-Commerce web application built with **Python 3.11**, **Django 5.2**, **HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed for high performance, modern cyber-luxe aesthetics, and seamless user experience.

---

## 🌟 Key Features

- **Segmented Dock Navigation**: Floating taskbar with active pill indicator.
- **Dynamic Product Catalog**: Filter by categories (Smartphones, Audio, Laptops, Wearables, Gaming) with price & rating sorting.
- **Instant Search with Live Autocomplete**: Real-time dropdown search with keyboard shortcut (`/`) and instant auto-scroll.
- **Interactive Shopping Cart & Wishlist**: Slide drawer cart with real-time subtotal, discount coupon calculator (`PRI23`), and state persistence.
- **Multi-Step Checkout System**: Shipping info, coupon validation, payment methods (Credit Card, UPI / QR, Cash on Delivery).
- **Order Tracking**: Track order status and shipment updates by Order ID.
- **Django Admin Panel**: Full database administration for Products, Categories, Orders, Order Items, and Coupons.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with fluid layouts and zero horizontal overflow.
- **Dark & Light Mode**: Seamless theme switching with persistent user preference.

---

## 🛠️ Technology Stack

- **Backend**: Python 3.11, Django 5.2
- **Database**: SQLite3 / MySQL compatible via Django ORM
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, Micro-Animations), Vanilla JavaScript (ES6+)
- **Icons**: Font Awesome 6
- **Typography**: Google Fonts (Inter, Outfit)

## 🚀 Quick Start Guide

### 1. Prerequisites
- Python 3.10+ installed
- Git installed

### 2. Clone the Repository
```bash
git clone <YOUR_REPOSITORY_URL>
cd "collage project E-commers web"
```

### 3. Install Dependencies
```bash
pip install django
```

### 4. Run Migrations & Seed Data
```bash
python manage.py migrate
python seed_db.py
```

### 5. Start Development Server
```bash
python manage.py runserver 8000
```
Open **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)** in your web browser.
